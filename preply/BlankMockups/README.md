# BlankMockups

Place all blank, unbranded mockups directly in this folder.

Supported formats: PNG, JPG, JPEG, WEBP.

Example:

BlankMockups/
  black-shirt-front.png
  white-hoodie-flatlay.jpg
  model-mockup-01.webp

STBZ AI saves placement presets for these mockups in placement.json after you click Save Preset.
