NorthWindUS = Store_A. Store_A holds NorthWindUS Etsy credentials and must never be reassigned to any other store or folder.

How store mappings work

  • The folder name (Store_A, Store_B, …) is the shared key between Preply and Batchly. Both tools must use the exact same value.
  • Preply reads store names from preply/data/stores.json. The store_folder field must match a Batchly driveFolderName.
  • Batchly stores are seeded via Prisma. Names in Batchly (e.g., "Store A") are display labels; the canonical identifier is the driveFolderName field.
  • Etsy credentials are linked to Batchly stores by ID. Reassigning a store's driveFolderName would sever the credential link for that store.
  • To update a store name in Preply: edit preply/data/stores.json directly. The store_folder value must not change for a store that already has Batchly credentials.
